FORGE FITNESS WEBSITE

Files:
- index.html: website structure and content
- style.css: layout, colors, responsive design and visual styling
- script.js: mobile navigation, current year and registration form demo behavior

HOW TO RUN:
1. Extract the ZIP file.
2. Keep all three website files in the same folder.
3. Double-click index.html to open it in a browser.

NOTES:
- The website uses online Google Fonts and Unsplash image URLs, so an internet connection is needed for those assets.
- Trainer names, contact details and membership prices are sample content. Replace them with your real details.
- The registration form currently validates input and displays a confirmation in the browser. It does not send or store submissions. Connect a backend or form service for real registrations.
